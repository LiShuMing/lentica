用户最新优先级：因CPU慢暂缓真实视频推理，保留已准备来源/窗口和代码，

## 验收与推广

先实际完成16个固定源的准备/原始摘要、窗口模型特征和不带标注的检索，
再对全量独立标注计分。标准库顺序组合的跨源、逆序、同时间/边界、过滤、
预算与稳定性由聚焦测试证明；真实视频的预测质量由实际报告证明。完整
workspace/pytest/Ruff/格式和打包解包检查记录在verification，不借旧结果。

此基线不预设模型必有收益，不改变默认方案。质量推广要求至少validation/
test原生单动作unit nDCG@10>=.5（六查询全部计入，空qrels为0）、较单帧提升
>=.05、正例顺序Top5命中>=.5（两步各有>=.5候选窗口被相应事件覆盖）；
本轮不作拒答调参，未校准的无答案结果率照实报告，不能宣称开放世界可用。
缺失任一证据或失败不能标记全部TODO完成。后续优化只在dev选择，验证冻结，
失败不由test修复。结果及局限写evaluation和0007执行清单。
