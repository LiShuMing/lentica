# M1：召回诊断与多模态机制实验

日期：2026-10-31。以下数字来自实际执行。先写规格、固定对照，再运行评测；

## 公开 SciFact：先定位遗漏阶段

沿用原有 5183 文档、300 查询、339 对正相关标注与已锁定的 BM25+字符配置。
该测试集已经看过，属于历史固定对照，不是新的封存测试集。自动查询类别仅为
表面形式启发式，不代表人工意图标签。指标为逐查询宏平均。

| 候选深度 | BM25 Recall | 字符路 Recall | 两路并集 Recall |
| --- | ---: | ---: | ---: |
| 每路前 50 | .870389 | .898667 | .922000 |
| 每路前 100 | .882556 | .922000 | .937667 |
| 每路前 200 | .918889 | .959333 | .963333 |

实际选中配置每路窗口为 50。该窗口下 BM25 独有 8 对相关关系，字符路独有
19 对。最终候选窗口 100 覆盖整个有界并集，因此本次融合候选截断损失为零。

339 对标注的去向为：

- 26 对没有进入两路各前 50 名的并集；
- 33 对已经进入融合候选，但没有进入最终前十；
- 280 对进入最终前十。

这是 query-document 对计数，不能与宏平均 Recall 的分母混用。候选宏平均
Recall=.922，最终=.836944。利用标注计算的候选 oracle nDCG@10 上限为
.923213；它只用于诊断，不参与实际排序，也不意味着真实重排能达到该上限。
扩大到每路 200 的并集覆盖是机会评估，未据此重调或切换配置。

## 固定规则重排：结果有得有失

预先固定规则：对融合后至多 50 个候选，优先排列原生/OCR/转写中包含查询精确
标识符的单元；caption 不作为精确证据，无标识符则保持原顺序。没有训练，
没有模型，没有按本次成绩扫描阈值。

| 对照 | Recall@10 | nDCG@10 | MRR@10 |
| --- | ---: | ---: | ---: |
| 原始 BM25 | .784278 | .662213 | .630243 |
| 既有 BM25+字符 | .836944 | .676097 | .629487 |
| 同配置+标识符规则重排 | .835833 | .677962 | .633701 |

相对既有混合，规则重排的 nDCG 差值为 .001865，配对查询 bootstrap 95%
区间为 [-.006470, .010343]，包含零；9 个查询改善、11 个退化、280 个持平。
MRR 略升、Recall 略降，不能宣称稳定质量提升。规则作为可替换实验保留，
不启用为产品默认。既有混合相对 BM25 的收益属于上轮结果，本轮只验证复现。

实际串行完整链路的第二次观察值：

| 链路 | p50 ms | p95 ms | 候选特征单元总数 | 最终读取 |
| --- | ---: | ---: | ---: | --- |
| BM25 分阶段对照 | 23.954 | 42.495 | 30000 | 300 次/3000 条 |
| 混合分阶段对照 | 79.385 | 105.342 | 22184 | 300 次/3000 条 |
| 混合+规则重排 | 86.390 | 112.154 | 22184 | 300 次/3000 条 |

最终每次最多 10 个资源；规则重排每次 50 单元，共 15000 单元。第一次对应
p50 为 23.684/78.093/79.178 ms。这是共享 CPU 的观察值，未做隔离性能实验，
不构成稳定开销或提速结论。耗时包括实际检索、候选特征、规则、聚合和内存
最终读取，不含索引构建；缓存候选对照另外检查排名一致。

## 多模态：受控图片与 PDF，不能外推模型效果

12 组独立生成条件，每组 18 张截图和 1 份八页 PDF，总计 228 个资源、312 个
检索单元、216 张图片、48 个查询。四类各 12 查询：标识符、颜色、组合、页面。
正确结果来自生成条件；包含近似错误码和故意有噪声的描述作为负例。

真实执行部分：PNG 像素读取及六色直方图、原生 PDF 文本提取、BM25、多路
RRF、资源聚合、定位与最终读取。OCR/描述是显式合成注释，没有运行 OCR 或
视觉语言模型。颜色路线只识别固定颜色词，无法识别物体、关系或通用语义。

| 固定对照 | Recall@10 | nDCG@10 | MRR@10 | 平均重复结果比例 |
| --- | ---: | ---: | ---: | ---: |
| 平铺单元文本检索 | .750000 | .657732 | .625000 | .393750 |
| 同文本路+资源聚合 | .750000 | .657732 | .625000 | 0 |
| 原文/OCR+描述+像素颜色，资源聚合 | 1.000000 | .940160 | .875000 | 0 |
| 同多路+标识符规则 | 1.000000 | .940160 | .875000 | 0 |

资源指标先按 ID 去重；重复比例在去重前计算。平铺基线只取前十单元，资源
聚合先取得有界候选再返回前十资源；候选预算差异是显式设计，不当作算法公平
性能比较。资源聚合消除了重复，在此数据上没有单独带来相关性增益。

分类型结果揭示了实际边界：

- 颜色查询 Recall 从 0 到 1，但多路 MRR 仅 .5、nDCG=.760640：噪声 caption
  仍能把颜色错误的图片排在首位。需要后续路线策略/证据核验，不能只看 Recall。
- 组合查询的 MRR 从 .5 到 1；标识符与页面查询相关性在本控制中没有下降。
- 页面类 12 个查询均将目标 PDF 第 3 页作为最佳命中；整体最佳单元定位命中
  从 .75 到 1。该定位指标是命中率，不是 bbox 或时间区间 IoU；后两者未评测。
- 规则重排在此多模态实验没有额外增益，不能把总收益归因于规则。

多路聚合每轮 48 次最终批量读取、共 168 个资源、每次最多 5 个。首轮本地
p50 约 .367 ms，平铺文本约 .081 ms；平铺基线未做最终读取，两者工作量不同。
这些小型合成索引耗时不代表真实图库、模型推理或磁盘服务性能。
