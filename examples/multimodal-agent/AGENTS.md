# Multimodal Agent Example

Follow root AGENTS.md and spec 0001. This is an optional interactive learning
example, not a background automation service. Imports/help/default commands must
not load dotenv, capture a screen, create a provider client, or execute GUI actions.
Actual image/screen analysis requires `--execute`; each GUI action additionally
requires interactive confirmation. Test with synthetic images and fake clients.
Keep screenshots and credentials outside source control. Never run this example
against a real desktop to verify a repository migration.
